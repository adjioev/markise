# Markise 0.1.0-beta.1

First public beta of **Markise**, a fast, cross-platform Markdown editor written in pure Rust.
This is an early preview: expect rough edges, and keep backups of important files.

## Downloads

| Platform | File | Notes |
|---|---|---|
| macOS 11 or later (Apple Silicon and Intel) | `markise-macos-universal.dmg` | unsigned, see below |
| Windows 10/11 x86_64 | `markise-windows-x86_64.zip` | unsigned, see below |
| Linux x86_64 (glibc 2.35 or later) | `markise-linux-x86_64.tar.gz` | X11 or Wayland |

Verify a download with `SHA256SUMS`: `shasum -a 256 -c SHA256SUMS --ignore-missing`
(macOS) or `sha256sum -c SHA256SUMS --ignore-missing` (Linux).
Each archive also contains `markise-cli` (command line: Markdown round-trip check and HTML
export), the licences (`LICENSE-MIT`, `LICENSE-APACHE`), `NOTICE` and `THIRD_PARTY/`.

## What works

- **Viewer**: renders CommonMark + GitHub Flavored Markdown (tables, task lists, strikethrough,
  footnotes, autolinks) with an outline and a file-tree sidebar; open a file or a whole folder.
- **Large files**: virtualised rendering; multi-megabyte documents open and scroll smoothly.
- **Themes and styles**: built-in themes (Drake, Lapis, Phycat), colour palettes (Tokyo Night,
  Catppuccin, Nord, Gruvbox, Rosé Pine, Dracula, …), separate style and colour choice, import of
  CSS themes, live reload of edited themes.
- **Code blocks**: syntax highlighting for the common languages (the syntax set of the `bat`
  project; see `NOTICE`).
- **Math**: TeX math, inline and display (KaTeX-compatible layout, bundled KaTeX fonts).
- **Diagrams**: Mermaid flowcharts and sequence diagrams, js-sequence and flowchart.js.
- **Editing in the rendered view**: click to place the caret; select by click, shift-click,
  drag, double-click (word) and triple-click (block); keyboard navigation (word, line, page,
  document); Markdown markers around the caret are revealed. Typing, Enter, Backspace and
  Delete follow the block rules (split and merge paragraphs, split headings, new list item,
  line break in code). Undo/redo with typing grouped; Paragraph and Heading 1–6 (⌘0–⌘6, Ctrl
  elsewhere) from the Paragraph menu.
- **Editing the source**: Source Code Mode (⌘/) and Side by Side view (Markdown source next to
  the rendered document, synchronised scrolling) with undo/redo; source edits are one undo
  step in the rendered view. Save; files changed on disk are detected and can be reloaded.
- **Export** (File → Export, runs in the background with progress and cancel):
  - **HTML** (self-contained, styled with the current theme) and **HTML without styles**;
  - **PDF**: paginated, selectable text, links, document outline (bookmarks), tagged PDF,
    header/footer template; page size and margins from front matter (default A4);
  - **Image (PNG)**: 640 px wide at 2× scale; very tall documents are split into several PNGs;
  - **Pandoc formats** (Word .docx, OpenDocument .odt, RTF, EPUB, LaTeX, MediaWiki,
    reStructuredText, Textile, OPML) — requires [Pandoc](https://pandoc.org) 2.10 or later
    installed separately;
  - custom export commands and a post-export command; "Export with Previous" repeats the last
    export in the session.
  - From the command line: `markise-cli html FILE.md -o FILE.html`.

## Known limitations

- Rendered-view editing is basic: no formatting shortcuts yet (⌘B, ⌘I, …), no input rules
  (typing `# ` or `- ` does not create a heading or list) and no list-specific rules beyond
  Enter; copy and paste are plain text; IME input commits text but does not show the
  composition (preedit) inline.
- One document per window; no tabs, no Quick Open, no search across a folder yet.
- No auto-update; download new versions from the Releases page.
- macOS and Windows builds are not code-signed (see below).
- Linux: a tarball only (no AppImage, .deb or Flatpak yet).
- Export follow-ups: no export settings dialog and no saved export profiles yet; remote and
  `data:` images are not fetched in PDF/PNG export (a placeholder with the alt text is drawn);
  fonts bundled with an imported CSS theme are not used in PDF/PNG export (system fonts are);
  no PNG font-size option.

## Installing

### macOS: opening the unsigned app

1. Open `markise-macos-universal.dmg` and drag **Markise** onto **Applications**.
2. The first time, **right-click (or Control-click) Markise in Applications → Open**, then
   confirm **Open**. On macOS 15 and later, if there is no Open button: try to open the app
   once, then go to **System Settings → Privacy & Security** and click **Open Anyway**.
3. Alternatively, remove the quarantine flag in Terminal:

   ```sh
   xattr -dr com.apple.quarantine /Applications/Markise.app
   ```

Markise registers for `.md` and `.markdown` files: use **Open With → Markise** in Finder, or
make it the default under **Get Info → Open with → Change All…**. The command-line tool
`markise-cli` is in the disk image too; copy it to a folder on your `PATH`.

### Windows

Extract the zip and run `markise.exe`. SmartScreen warns about an unrecognised app because the
build is unsigned: click **More info → Run anyway**. To open Markdown files with Markise,
right-click a `.md` file → **Open with → Choose another app** → browse to `markise.exe`.

### Linux

```sh
tar xzf markise-linux-x86_64.tar.gz
cd markise-*-linux-x86_64
./markise FILE.md
# optional: install for the current user (menu entry, icon, "Open with")
mkdir -p ~/.local/bin && cp markise markise-cli ~/.local/bin/
cp -r share ~/.local/
```

Runtime libraries (normally present on desktop systems): OpenGL/EGL, libxkbcommon, and
Wayland or X11 client libraries.

## System requirements

- macOS 11 Big Sur or later, Apple Silicon or Intel.
- Windows 10 or 11, x86_64, OpenGL 3.x-capable graphics driver.
- Linux x86_64 with glibc 2.35 or later (Ubuntu 22.04, Debian 12, Fedora 36 and newer), X11 or
  Wayland, OpenGL 3.x / OpenGL ES 3.0.

## Reporting issues

Please open an issue at https://github.com/adjioev/markise/issues with:
the Markise version (`0.1.0-beta.1`), your OS and version, what you did, what you expected and
what happened, and if possible a small Markdown file that shows the problem.

For crashes, attach the log file `markise.log`. It holds start lines (version, OS), crash
locations with a backtrace and fatal errors — never document contents — and stays under 1 MB
(the previous part is kept as `markise.log.1`):

| OS | Log folder |
|---|---|
| Windows | `%LOCALAPPDATA%\Markise\logs\` |
| macOS | `~/Library/Logs/Markise/` |
| Linux | `$XDG_STATE_HOME/markise/logs/` (usually `~/.local/state/markise/logs/`) |

Starting Markise from a terminal also shows its output there (on Windows too:
`markise.exe FILE.md` from Command Prompt or PowerShell).
